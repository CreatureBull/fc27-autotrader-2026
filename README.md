## 📋 Overview

EA Sports FC 27 launched globally on September 25, 2026. The Web App opened on September 16, giving traders early access to the transfer market before the game even unlocked. Prices fluctuate wildly in the first days — cards listed at 18,000 coins might not sell if buyers only have 15,000, while the same card can drop to 12,000 when someone needs quick coins.

Manual trading means staring at a screen, refreshing searches, and racing other players to undercut listings. It's time-consuming, repetitive, and easy to miss opportunities.

**FC 27 AutoTrader** automates the workflow. It searches the market by your filters, places bids, executes purchases, and relists items — all according to rules you configure. It runs as a separate desktop application and operates through the Web App interface.

**Who it's for:** experienced Ultimate Team traders in the US and Europe who want to automate routine market activity and focus on strategy instead of clicking.

## ❓ FAQ

**Will I get banned for using this?**  
The application runs as a separate desktop process and does not modify game files or memory. However, EA's rules prohibit the use of external tools or bots for unfair advantage. Automated trading may violate the spirit of these rules. Use on secondary accounts if concerned.

**Does it work with the Companion App?**  
Yes — the tool operates through the FC 27 Web App interface. Transfer market access in the Web App is tied to your account history and active play days.

**Do I need to disable my antivirus?**  
Some antivirus suites may flag the automation process as a false positive. Add an exclusion for the tool folder if needed.

**What is the transfer market access requirement?**  
EA uses a tiered access system. Returning veterans typically get immediate access. New accounts may need to complete foundation objectives and wait 24-48 hours.

**Can I run multiple instances?**  
The tool supports multiple account profiles, but running simultaneous instances may trigger rate limits or detection.

**How do I uninstall?**  
Run `FC27AutoTrader.exe --uninstall` — it removes the tool, profiles, and registry entries without touching your game files.
